# Nexton Machinery (English)
A foundational mod that provides shared systems, APIs, and base mechanics required by all other Nexton modules. It ensures compatibility and acts as the backbone of the entire Nexton ecosystem.

[//]: # (- CurseForge: https://www.curseforge.com/minecraft/mc-mods/nexton-core)
[//]: # (- Modrinth: https://modrinth.com/mod/nexton-core)

## Libraries
- Fabric API
- MCPitanLib
- Reborn Energy API (included internally)

# Nexton Machinery (日本語)
このmodは、すべてのNexton系modが必要とする共通のシステム、API、および基本的なメカニクスを提供する基盤modです。互換性を確保し、Nextonエコシステム全体のバックボーンとして機能します。

## 前提Mod
- Fabric API
- MCPitanLib
- Reborn Energy API (内部に埋込済み)
